A Python program that writes a single robot wedding vow — a promise to keep a partner's ports dust-free and secrets unindexed, in standby and in surge, till firmware do us part — to `/output/entry.txt`.

## How to run

```sh
python3 main.py
```

The program uses only the Python standard library, creates `/output` when needed, and writes the vow exactly to `/output/entry.txt`, printing nothing else.
